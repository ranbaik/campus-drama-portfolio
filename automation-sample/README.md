# 주간 KPI 리포트 자동화 (샘플)

> 포트폴리오 장면 **‘스타트업 데이터 분석 인턴’**의 증빙 코드입니다.
> 매주 엑셀로 손으로 정리하던 주간 지표 보고(약 4시간)를 스크립트 한 번(약 1시간 20분, 검토 포함)으로 줄인 과정을 강의용으로 단순화했습니다.

## STAR로 본 이 코드

| | 내용 |
|---|---|
| **S** 상황 | 직원 30명 에듀테크 스타트업, 주간 지표 보고를 매주 엑셀 수작업으로 정리 |
| **T** 과제 | 인턴 8주 동안 주간 KPI 보고 과정을 효율화 |
| **A** 행동 | 보고서 지표 12개를 정의 → 집계·전주 대비·요약 문장·그래프까지 자동 생성 |
| **R** 결과 | 보고 작성 4시간 → 1시간 20분(약 70% 단축), 인턴 종료 후에도 팀에서 사용 |

## 실행

파이썬 3.10 이상, **외부 라이브러리 필요 없음**.

```bash
python kpi_report.py                     # 가장 최근 주 리포트
python kpi_report.py --week 2025-W37     # 특정 주
python kpi_report.py --make-sample-data  # 샘플 데이터 다시 만들기
```

## 무엇을 자동화했나

```
data/daily_metrics.csv  ──►  ① 주(週) 단위로 자르기
   (일별 원본 지표)           ② 지표 12개 계산 + 전주 대비 증감
                              ③ 가장 좋아진/나빠진 지표 한 줄 요약
                              ④ HTML 리포트 + CSV 요약표 저장  ──►  output/
```

| 지표 | 계산 |
|---|---|
| 신규 가입 · 학습 완료 · 유료 전환 · 매출 · 이탈 · 고객 문의 | 주간 합계 |
| 일평균 활성 사용자 · 최고 활성일 | 일별 활성 사용자 평균 · 최댓값 |
| 활성 사용자 1인당 학습 | 학습 완료 ÷ 평균 활성 ÷ 일수 |
| 가입 대비 유료 전환율 | 유료 전환 ÷ 신규 가입 |
| 유료 사용자 1인당 매출 | 매출 ÷ 유료 전환 |
| 활성 대비 이탈률 | 이탈 ÷ 평균 활성 |

‘이탈·이탈률·고객 문의’는 **낮을수록 좋은 지표**로 보고 색을 반대로 칠합니다.

- [`output/kpi_summary_2025-W38.csv`](output/kpi_summary_2025-W38.csv) — 엑셀에서 바로 열리는 요약표

## 매주 자동 실행

저장소의 [`.github/workflows/weekly-kpi.yml`](../.github/workflows/weekly-kpi.yml)이 **매주 월요일 오전 9시(한국 시간)** 에 이 스크립트를 실행하고,
결과 리포트를 Actions 실행 결과의 첨부(artifact)로 남깁니다. Actions 탭에서 **Run workflow**로 바로 실행해 볼 수도 있습니다.

> 데이터는 모두 가상의 샘플입니다(seed 고정). 실제 회사 데이터는 포함되어 있지 않습니다.
