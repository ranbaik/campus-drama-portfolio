# 캡스톤: 캠퍼스 셔틀 대기시간 예측 (샘플)

> 포트폴리오 장면 **‘캡스톤: 캠퍼스 셔틀 대기시간 예측’ (2025년 1학기)** 의 증빙 자료입니다.

- 📕 **발표 자료**: [`shuttle_slides.pdf`](shuttle_slides.pdf) (6쪽)
- 💾 **모델 코드**: [`shuttle_model.py`](shuttle_model.py) — 표준 라이브러리만으로 최소제곱 회귀를 직접 구현
- 📈 **결과**: [`output/metrics.json`](output/metrics.json)

| | 내용 |
|---|---|
| **S** | 등하교 시간 셔틀 대기 불만이 학생 게시판에 매주 올라왔다 |
| **T** | 3인 팀에서 데이터 수집과 예측 모델 담당 |
| **A** | 6주 동안 정류장별 승하차 인원을 직접 기록(약 2,400건), 요일·시간·날씨를 변수로 회귀 모델 |
| **R** | 예측 안내 정확도 85%(±3분 이내), 시범 운영 기간 평균 체감 대기 12분 → 7분 |

## 실행

```bash
python shuttle_model.py
```

1. `data/shuttle_log.csv` — 가상 관측 데이터 2,400건 생성 (seed 고정)
2. 학습 80% / 검증 20%로 나눠 `대기시간 = β₀ + β₁·대기인원 + β₂·피크 + β₃·비 + β₄·월금` 추정
3. 검증 데이터에서 ±3분 이내 비율(정확도)과 평균 오차 계산 → `output/metrics.json`
4. 결과 숫자를 넣어 발표 자료 원본 `output/shuttle_slides.html` 생성 (→ 브라우저 인쇄로 PDF)

> 데이터와 인물은 모두 가상의 샘플입니다.
