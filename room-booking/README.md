# 강의실 예약 웹앱 — 예약 충돌 처리 로직 (샘플)

> 포트폴리오 장면 **‘팀 프로젝트: 강의실 예약 웹앱’ (2024년 1학기)** 의 증빙 코드입니다.
> 4인 팀에서 제가 맡은 **백엔드 · 예약 충돌 처리** 부분만 떼어 내 강의용으로 단순화했습니다.

| | 내용 |
|---|---|
| **S** | 학과 세미나실 예약을 종이 장부로 하다 보니 중복 예약 불만이 많았다 |
| **T** | 4인 팀에서 백엔드와 예약 충돌 처리 로직을 맡음 |
| **A** | 학과 조교님 인터뷰로 요구사항 5개(R1~R5)를 정리 → 아래 규칙으로 구현 |
| **R** | 학과 학생 30명이 한 학기 사용, **중복 예약 0건** |

## 요구사항 → 코드

| 규칙 | 내용 | 위치 |
|---|---|---|
| R1 | 같은 방에서 시간이 겹치면 불가 (끝 = 다음 시작은 허용) | `Booking.overlaps` |
| R2 | 30분 단위, 30분 ~ 3시간 | `_validate_shape` |
| R3 | 운영 시간 09:00 ~ 22:00 | `_validate_shape` |
| R4 | 한 사람 하루 최대 2건 | `add` |
| R5 | 충돌 시 가장 가까운 빈 시간 추천 | `suggest` |

## 실행

```bash
python booking.py                    # 데모
python -m unittest -v test_booking.py   # 규칙별 테스트 7개
```

데모 출력:

```
예약 2건 등록:
  김민수 13:00-15:00
  이서연 15:00-16:00

홍길동 14:00-15:30 → 거절: 13:00~15:00에 이미 예약이 있어요.
  추천 시간: 16:00~17:30
```

> 인물·데이터는 모두 가상의 샘플입니다.
